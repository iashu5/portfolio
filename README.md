# Ashutosh Kumar · Portfolio

Personal portfolio of **Ashutosh Kumar**, .NET Full Stack Developer (C#, ASP.NET Core, Web API, SQL Server, React).

🌐 Live: https://ashucodes.netlify.app

## Tech stack
React 18 · TypeScript · Vite · Tailwind CSS · Framer Motion · Netlify Forms

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
```

## Update content
All text (experience, projects, skills, links) lives in [`src/data.ts`](src/data.ts).
The photo and resume are in `public/`.

## Deploy
```bash
npm run build    # outputs to dist/
```
Then drag the `dist` folder onto the site's **Deploys** page in Netlify.
